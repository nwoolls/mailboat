# Contributing

Thanks for looking. A few ground rules keep this project small and safe.

## Bug reports and ideas: welcome

Open an issue using one of the forms. For a bug, the version, whether you're on
Mac or Windows, and the steps to see it help most. Please never paste real
email or tokens; the sync log (`sync.log`) holds no email content and is safe
to attach.

## Code: not accepted

Pull requests from outside are closed without review. An email client is an
attractive target for a malicious change, and keeping the copyright with the
owner means the licence can change later. If you've found a fix, describe it in
an issue and it will be written here.

## Security problems

Don't use an issue. See [SECURITY.md](SECURITY.md).
