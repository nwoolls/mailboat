# Contributing

Thanks for looking. A few ground rules keep this project small and safe.

## Bug reports and ideas: welcome

Open an issue using one of the forms. For a bug, the version, whether you're on
Mac or Windows, and the steps to see it help most. Please never paste real
email or tokens, and describe a problem in general terms (made-up names and
addresses are enough to show it); the sync log (`sync.log`) holds no email content, but it does name
accounts and activity. Look it over first and remove account names and
addresses, counts, timings and timestamps, file paths and any error text
that identifies mail, then attach only the relevant lines.

Questions and setup help go in
[Discussions](https://github.com/nwoolls/mailboat/discussions), so issues stay
for bugs and ideas.

## Code: not accepted

Pull requests from outside are closed without review. An email client is an
attractive target for a malicious change, and keeping the copyright with the
owner means the licence can change later. If you've found a fix, describe it in
an issue and it will be written here.

## Security problems
